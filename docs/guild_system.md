# 길드 의뢰 게시판과 모험가 등급

## 현재 구현 — 1차 반복의뢰 (2026-10-03)
- 큰 마을 길드 홀 앞 **의뢰 게시판** 또는 길드장 하르트에게서 의뢰창을 연다.
- 게시판에는 한 번에 6개가 생성된다.
- 동시에 진행할 수 있는 의뢰는 최대 3개.
- 현재 4종:
  1. 일반 몬스터 일정 수 처치
  2. 현재 티어의 특정 몬스터 처치
  3. 현재 티어에 맞는 던전 지정 층 도달
  4. 특정 무역품 납품
- 게시판이 완전히 소진되고 진행 중 의뢰도 없으면 다음 세트가 자동 생성된다.
- 의뢰 진행·게시판 상태·완료 횟수는 arpg_save_v3에 저장된다.

### 보상
- 기본 EXP: 현재 레벨 필요 경험치의 약 **8%**.
- 골드: 현재 레벨·티어에 따라 증가.
- 약 28% 확률로 현재 티어 랜덤 장비 보상.
- 장비 가방이 가득 찼으면 장비 대신 추가 골드.
- 납품 의뢰는 실제 무역품 화물에서 필요한 수량을 차감한다.

## 아직 가안 — 모험가 등급/승급
예전 5단계 등급안은 현재 **확정 규칙이 아니다.** 게임 전체가 Lv1~70 / T1~T7 구조로 바뀌었기 때문에 추후 다시 맞춘다.

후보 방향:
- 의뢰 완료 횟수와 승급 시험을 이용해 길드 등급을 올린다.
- 승급 시험은 지정 던전층 돌파, 지명 몬스터 처치 등.
- 응시료·인증비·회비 등은 루크레아의 돈 빠져나갈 곳으로 활용.
- 높은 등급은 고급 의뢰, 길드 상점, 감정/마법부여/재굴림 할인 등과 연결 가능.
- 흥정 계열 옵션과 의뢰 보상 협상도 후보.
