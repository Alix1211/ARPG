- 시연은 현자의 숙소에서만 가능. 선택 기술을 잠시 발동 가능한 단계로 만든 뒤 즉시 기존 학습 값으로 복구. 스킬·금화 저장 데이터는 변경하지 않음. 마나 임시 공급은 시연 직후 복구. 버프는 시연 뒤 남은 시간 작동함.
