# 효과음 목록 (지금은 코드 합성음, 파일을 넣으면 자동 교체)

진짜 효과음 파일을 만들면 `assets/sfx/<이름>.mp3`로 넣고 `python3 src/town/build.py`. 1초 안팎, 짧고 작게.

| 이름 | 언제 | 느낌 |
|---|---|---|
| swing | 검 휘두르기 | 짧은 바람 가르는 소리 |
| thrust | 창 찌르기 | 날카로운 바람 |
| punch | 건틀릿 | 둔탁한 주먹 바람 |
| bow | 활 쏘기 | 시위 튕김 + 화살 바람 |
| staff | 지팡이 구슬 | 부드러운 마법 울림 |
| hit | 맞힘 | 퍽 (둔탁) |
| crit | 치명타 | 퍽 + 반짝 |
| kill | 몬스터 쓰러짐 | 펑 사라짐 |
| hurt | 엘프가 맞음 | 아얏 대신 둔탁한 충격 |
| fire / ice / heal / slash / spin | 스킬 | 불덩이 / 얼음 화살 / 치유 / 강하게 베기 / 회전 베기 |
| coin | 금화 줍기 | 짤랑 |
| buy | 물건 삼 | 짤랑 + 계산대 |
| item | 장비 주움 | 가벼운 획득음 |
| potion | 물약 마심 | 꿀꺽꿀꺽 + 반짝 |
| chest | 상자 열기 | 나무 삐걱 + 보물 반짝 |
| mimic | 미믹 | 낮은 으르렁 |
| travel | 장소 이동 | 바람 휘익 |
| stairs | 계단 | 발소리 네 번 |
| tick | 버튼 | 작은 똑 |
| nope | 안 됨 | 작은 툭 |

배경음악(마을·성 밖·필드 테마별·던전)은 아직 없음. 받으면 assets/bgm/ 에 넣고 연결하면 된다.
