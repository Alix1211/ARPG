# 효과음 목록 (기본은 코드 합성음, 파일을 넣으면 자동 교체)

진짜 효과음 파일을 만들면 `assets/sfx/<이름>.mp3`로 넣고 `python3 src/town/build.py`. 1초 안팎, 짧고 작게.

| 이름 | 언제 | 느낌 |
|---|---|---|
| swing | 검 휘두르기 | 짧은 바람 가르는 소리 |
| thrust | 창 찌르기 | 날카로운 바람 |
| punch | 건틀릿 | 둔탁한 주먹 바람 |
| bow | 활 쏘기 | 시위 튕김 + 화살 바람 |
| staff | 지팡이 구슬 | 부드러운 마법 울림 |
| hit | 맞힘 | 퍽 (둔탁) |
| crit | 치명타 | 퍽 + 반짝 |
| kill | 몬스터 쓰러짐 | 펑 사라짐 |
| hurt | 엘프가 맞음 | 아얏 대신 둔탁한 충격 |
| fire / ice / heal / slash / spin | 스킬 | 불덩이 / 얼음 화살 / 치유 / 강하게 베기 / 회전 베기 |
| coin | 금화 줍기 | 짤랑 |
| buy | 물건 삼 | 짤랑 + 계산대 |
| item | 장비 주움 | 가벼운 획득음 |
| potion | 물약 마심 | 꿀꺽꿀꺽 + 반짝 |
| chest | 상자 열기 | 나무 삐걱 + 보물 반짝 |
| mimic | 미믹 | 낮은 으르렁 |
| travel | 장소 이동 | 바람 휘익 |
| stairs | 계단 | 발소리 네 번 |
| tick | 버튼 | 작은 똑 |
| nope | 안 됨 | 작은 툭 |

## 배경음악

`assets/bgm/`의 CC0 음악 네 곡을 빌드에 포함한다. 마을은 마을곡, 성 밖과 7개 필드는 필드곡, 던전은 던전곡이다. 던전 우두머리가 추적하거나 가까워지면 보스곡으로 바뀌고 쓰러지면 던전곡으로 돌아간다. 이동할 때는 1.4초 동안 교차하고, 음악은 첫 입력 뒤에 시작한다. 기존 `소리 켬/끔` 버튼으로 음악과 효과음을 함께 끈다.

현재 빌드는 그림·음원을 `game/art_<해시>.js`에 따로 담으므로, `town.html`만 따로 복사하면 음악이 나오지 않는다. GitHub Pages와 Android 앱에서는 두 파일을 함께 받는다. 개별 음원의 출처와 CC0 확인 기록은 [audio_licenses.md](audio_licenses.md)에 있다.
