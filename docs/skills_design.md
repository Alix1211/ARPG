# 액티브 스킬 설계 (케인 확정 — 초기 기획 대화에서 정한 내용을 저장소에 옮김, 2026-10-04)

이 내용은 처음 기획 대화에서 확정됐으나 저장소 문서에 없어서 구현 담당(GPT)이 볼 수 없었다. 아래는 케인이 말한 것만 적었고, 스킬 이름·마나·수치·이펙트는 **미정**이다(구현 때 제안해서 케인 승인).

## 구성: 9개 줄 × 3개 = 27개

- 지팡이는 무기 전용 스킬이 없다. 마법 스킬이 그 역할을 한다.
- 구현 완료: fire1(불덩이), ice1(얼음 화살), holy1_heal(치유), sword1(강하게 베기), sword2(회전 베기). 나머지 22개 미구현.

## 규칙
- 스킬은 **레벨업 스킬 포인트로만** 배운다(능력치 포인트와 별도 주머니). 액티브·패시브가 같은 스킬 포인트를 쓴다.
- 아이템은 스킬을 직접 가르치지 않는다. 접미사 옵션으로 **이미 배운 스킬의 단계를 올린다**(예: 불 스킬 +1).
- 퀵슬롯 5칸: 지금 든 무기에 맞는 스킬 최대 3개 + 다른 무기 스킬 2개까지. 마법 스킬은 지팡이 속성과 무관하게 배운 것을 쓴다.
- 기본 공격: 지팡이는 지팡이 속성을 따른다(뇌전 지팡이면 뇌전 기본 공격). 검·창·활·무투는 속성 없는 물리.
- 무기 공격 모양: 검 초승달 휘두르기 / 창 찌르기 / 활 빠른 직선 / 무투 두 번 때리기(각 50%, 목 높이·배 높이).
- 백마법 부활: 단계가 낮을 때는 대가가 있고, 끝까지 찍으면 대가가 거의 없다. **대가의 내용은 미정**(후보: 가진 돈 일부 / 약한 체력으로 부활).
- 무기 스킬을 마법처럼 "일반/중급 광역/큰 광역" 3개씩 두는 것으로 이해하고 있으나, 무기별 세부 성격은 구현 때 케인과 확정.

## 구현 순서 제안
속성별로 한 줄씩(3개) 구현 → 케인 확인 → 다음 줄. 이펙트는 `src/town/vfx.js`의 매핑에 이름만 추가(뇌전·암흑·독 폭발 그림이 `assets/vfx`에 있음, 위 STATUS 참고). 수치는 100배 개편(STATUS 참고) 때 함께 맞추므로 지금은 상대 강도(일반 < 중급 < 큰) 비율만 정해 둘 것.

## 제안안에서 우리 설계와 어긋나 바로잡을 점
- 보고서는 "지팡이 기본 타격이 배운 마법의 속성을 띤다"고 썼으나 확정 설계는 **지팡이 자체 속성을 따른다**(스킬은 지팡이와 무관).
- 뇌전의 "마비", 암흑의 "독/출혈" 상태이상은 현재 상태이상 목록(화상·둔화·빙결·석화·출혈)에 없다. 마비는 석화나 빙결로 대체하거나 새로 만들지 케인과 결정.
- 창 투창·강하 찌르기(도약), 무투 돌진·준비동작 캔슬, 마법 장판 등은 **새 기능이 필요**해서 구현 난이도가 다르다. 쉬운 것(투사체·부채꼴·자기 중심 원형)부터 구현.

## 제안된 밸런스 보완책 5가지 (채택 여부 케인 결정)
1. 마법 시전 후 딜레이를 든 무기의 공격 간격에 맞춤(지팡이 연사 폭딜 방지).
2. 큰 광역 시전 시 0.5~1초 제자리 멈춤(활 카이팅+궁극기 무한 반복 방지).
3. 정예·보스는 경직 1회 후 3~5초 경직 면역(건틀릿 무한 경직 방지).
4. 스킬 사용 직후 모든 슬롯 1~1.5초 글로벌 쿨다운(궁극기 5개 동시 난사 방지).
5. 치유 연속 사용 시 마나 소모 누적 증가 / 방어막 중 마나 회복 정지(무적 수비 방지).
