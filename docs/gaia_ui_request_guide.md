# 가이아 UI 이미지 요청 가이드 (GPT용, 2026-11-03)

케인이 GPT에 직접 올려서 요청한다. 방식은 케인이 정한 대로 **화면 캡처 + 위치 + 쓰임 + 코드로 그린 설계도**를 함께 준다.
이미 받은 그림(UI 키트 시트, 세 명 전신, 카일 초상)은 다시 요청하지 않는다. 새로 필요한 것만 적었다.

## 올릴 그림 (`source_sheets/gaia_ui/request/`)
| 파일 | 내용 | 어느 요청에 같이 올리나 |
|---|---|---|
| `01_HUD_전체_번호.png` | 지금 화면 + ①~④ 번호 상자와 한 줄 설명 | ①②③④ 전부 |
| `02_HUD_확대_치수.png` | 같은 자리를 2배 확대, 치수 적음 | ①②③④ |
| `03_캐릭터탭_잠금.png` | 스킬창 캡처 + ⑤ 탭 자리 · ⑥ 잠금 자리 | ⑤⑥ |
| `04_카일스킬_아이콘_8종.png` | 아이콘 8칸 틀 + 스타일 참고 | 카일 스킬 아이콘 |

| `../ui_kit_steel_blue_original.png` | 이미 준 UI 키트 (재질 참고) | 전부 |

캡처는 화면(1280×720)의 **2배(2560×1440)** 이고, 요청 크기는 모두 이 2배 기준 px이다.

## 번호별 요청
공통: **투명 배경 PNG, 그림 안에 글자·숫자 넣지 않기(글자는 코드가 씀), 재질은 UI 키트(강철+가죽+청색), 빨강은 체력, 금색은 M 임시.**

| 번호 | 만들 것 | 크기(px) | 상태·개수 |
|---|---|---|---|
| ① 동료 카드 | 카드 틀 1장(두 명 공용). 왼쪽에 둥근 초상 자리(56×56, 비움), 오른쪽에 HP 틀 200×16과 M 틀 200×12(비움) | 300×72 | 1장 |
| ①-b 게이지 채움띠 | HP 빨강 200×16, M 금색 200×12(색은 임시), 쓰러짐용 회색 200×16. 가로로 늘어나도 깨지지 않게 | 위 크기 | 3장 |
| ② 동료 집합 버튼 | 글자 없는 버튼 틀 | 152×66 | 보통 / 눌림 / 비활성(회색) |
| ③ 기본 공격 다이얼 | 지금 X자 다이얼(무기 4칸)을 **방망이(왼쪽 반)·채찍(오른쪽 반) 두 칸**으로. 같은 캔버스 같은 위치로 4장 | 320×320 | 전체 / 방망이 켜짐 / 채찍 켜짐 / 중앙 버튼(보통·눌림) |
| ④ 스킬 버튼 틀 | 원형 틀, 가운데 지름 약 80px는 투명(스킬 아이콘이 들어옴) | 112×112 | 빈 칸 / 사용 가능 |
| ⑤ 캐릭터 탭 | 장비창·스킬창 공통, 카일·아가사·실비아용 원형 탭. 안쪽 초상 자리는 비움 | 약 110 지름(128×128 이내) | 선택 / 비선택 / 비활성 |
| ⑥ 잠금 덮개 | 반투명 어두운 원 + 작은 자물쇠. 아래 아이콘이 희미하게 비침 | 128×128 | 1장 |
| ⑦ 카일 스킬 아이콘 | 8종을 한 장에 4×2로. "어두운 원형 메달 + 가운데 밝은 모티프" | 칸당 256×256 | 8종 |

## 카일 스킬 아이콘 모티프 (제안 — 케인 확인 전)
1. 긴급매질 — 방망이 + 불꽃 튀는 하트
2. 몰아치기 — 방망이 잔상 3개
3. 정신 차려 — 손바닥 + 별
4. 긴급 허세 — 근육 팔 + 불꽃
5. 긴급 S파워 — 채찍이 감긴 하트
6. 긴급 독무 — 초록 독안개 구름
7. 긴급 도망 — 발자국 + 먼지 + 문
8. 긴급 M파워 충전 — 하트 둘 + 자석 + M

## GPT에 붙일 말 (복사해서 쓰기)
> 첨부한 화면 캡처는 게임의 현재 HUD입니다. 번호 상자가 바꿀 위치이고, 설계도(05)에 칸 경계와 크기(px)가 있습니다. 번호별로 설명한 크기·상태 수대로 **투명 배경 PNG**를 만들어 주세요. 재질은 함께 올린 UI 키트(강철·가죽·청색)와 맞춰 주세요. **그림 안에 글자와 숫자는 넣지 마세요.** 칸이 비어야 하는 곳(초상, 게이지 안, 스킬 아이콘 자리)은 비워 주세요. 번호별로 한 장씩(또는 한 시트에 칸을 나눠) 주시고, 크기는 정확히 맞춰 주세요.

## 코드에서 처리하는 것 (요청하지 않음)
이름·HP·M 글자, 게이지 길이, 쿨다운 어둡게, 누르는 효과, 컷인 확대, 스킬 이펙트와 애니메이션.

## 아직 정해지지 않은 것 (케인 결정 전)
- HP/M 게이지 색: 빨강 + 금색은 **임시**.
- 카일 아이콘 모티프 8개는 제안안.
- 컷인 그림(19금)은 아직 받지 않음 — 스킬 확정 뒤 별도 요청 시트를 만든다.
- 실내 건물 그림은 퀘스트를 다 만든 뒤에 결정.

생성기: `tools/gaia_request_sheets.py <HUD 2배 캡처> <스킬창 2배 캡처>` (캡처가 바뀌면 다시 돌리면 됨).
