# 능력치·스킬·성장 (케인 구상, 2026-10-03)
## 능력치
- 레벨업 때마다 능력치 점수 5점(10의 배수 레벨은 10점)을 받아 케인이 직접 골라 찍음: 힘·체력·지능·마력·민첩. (케인: 5포인트 이상, 직접 선택)
- 운은 찍을 수 없음: 레벨업마다 자동 +1(가안), 무기 숙련·아이템으로도 조금씩.
- 스킬 점수는 따로: 레벨업마다 1점(가안).
- 힘·체력·지능·마력·민첩: 레벨업 점수로 직접 찍음. 체력→HP, 마력→MP.
- 운: 직접 못 올림. 레벨업과 아이템으로만 오름(여러 곳에 영향).
## 무기 숙련 (두 번째 성장 갈래, 영구·감소 없음)
- 쓰면 자동 상승. 숙련 레벨 1당 3.0을 6개 능력치에 나눠 줌 → 표는 docs/weapons.md 2번 (케인: 3개 능력치만으로는 안 됨, 6개로 세분화)
## 스킬
- 마법 5계열(불·얼음·뇌전·암흑·백마법) × 3개(일반 공격·중급 광역·큰 광역). 백마법 = 힐·방어막·부활(다 찍으면 페널티 거의 없음, 낮은 단계 페널티 미정)
- 무기 전용 스킬: 검·창·활·무투 각 3개. 마법 15 + 무기 12 = 27개, 같은 스킬 점수로 배움
- 능력치 점수와 스킬 점수는 따로 받음
- 아이템 옵션은 배운 스킬 단계 보너스("불 스킬 +1")
- 스킬 칸 최대 5, 가진 스킬 자유 배치 (최신 확정. 이전의 "현재 무기 3 + 다른 무기 2" 안은 대체됨)
## 기본 공격
- 검=초승달 휘두르기, 창=찌르기, 무투=50% 대미지 2연타, 활=빠른 직선, 지팡이=지팡이 속성 따름


## 주인공
- 이름: **루크레아 (Lucrea)**.
- 정통 판타지 엘프처럼 보이지만 돈·흥정·파밍에 밝은 성격. 이름은 lucre(돈·이익)의 어감과 스크루지를 연상시키는 방향.

## 스킬 포인트 운용 (케인 확정 2026-10-03)
- 일반 스킬과 패시브 스킬은 **같은 스킬 포인트**를 쓴다.
- 레벨업 때 받은 스킬 포인트를 바로 쓸 필요가 없으며, **아껴 두었다가 원하는 빌드에 몰아 찍을 수 있다.**
- 생활스킬은 이 포인트를 먹지 않는다. 초반 레벨 구간에서 하나씩 자동 해금한다.

### 패시브: 마력 유도
- 마법 투사체가 **가장 가까운 적을 우선 추적**한다. 위·아래 조준 스트레스를 줄이고 활과 조작감을 구분한다.
- Lv.1: 부드러운 유도 / Lv.2: 강한 유도 / Lv.3: 거의 확실한 추적.
- 실제 캐릭터 성장에서는 초반 패시브로 열고 스킬 포인트로 올린다.
- **현재 시험판은 체감 확인을 위해 Lv.1을 기본 활성화**한다. 불덩이·얼음 화살·지팡이 구슬에 적용.

## 생활스킬 6종
생활스킬은 전투 스킬 포인트와 분리한다. 아래 레벨은 초반 배치 가안이며, 플레이 속도를 보고 숫자만 조정한다.

1. **타운 포탈** — Lv.2 해금. 마을로 귀환.
2. **감정** — Lv.4 해금. 미확인 아이템을 직접 감정.
3. **디스카운트** — Lv.6 해금. 상점 구매가 절감. 레벨업 가능.
4. **오버카운트** — Lv.8 해금. 판매할 때 값을 더 받음. 레벨업 가능.
5. **마법부여** — Lv.10 해금. 장비 옵션 부여/재부여 계열. 레벨업 가능.
6. **돈 냄새** *(이름·세부효과 가안)* — Lv.12 해금. 희귀 드랍·보물·상점 희귀품과 관련된 강한 파밍 보조 생활스킬로 설계.

- 마법부여·디스카운트·오버카운트의 구체적인 레벨 상승 방식은 아직 미확정. 전투 스킬 포인트를 소모시키지는 않는다.
