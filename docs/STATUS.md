# 현재 상태 (대화가 끊겨도 여기부터 읽을 것)

**장르 한 줄: 돈 밝히는 엘프의 코믹 자본주의 파밍 액션 코믹 롤플레잉**
**제목 후보(케인): 자본주의 엘프의 이세계 모험기**
## 가장 중요한 원칙 (디자인)
- **한 씬 한 컷을 만들더라도 최종 상태 수준으로 만든다.** 대충 만들고 나중에 고치자는 방식 금지(두 번 일하게 되고 결과가 망가진다). 예전 테스트판 위에 덧대어 키우는 관성도 금지.
- 디자인은 싹 리빌드. 옛 그림과 새 그림을 찢어붙인 화면은 절대 안 됨.
- 기준: ① 통일감 ② 모션의 일치.
- 케인이 에셋으로 시안을 만들어 주면 그걸 참조해서 만든다. 설명 듣기 전엔 임의로 그리지 않는다.
  (HUD 시안은 받음 → docs/hud_controls.md. 마을은 케인 지시로 "일단 만들어 보고, 안 되면 GPT에게 구역별 한 장 지도를 그리게 해서 이어 붙인다". 마을은 클 필요 없음.)

## 세계 구조 (케인 확정 2026-10-03)
- 큰 마을(지금 만든 마을, 시나리오 중심) + 지역마다 작은 마을(상점 1~2, 여관만 있는 고정 쉼터, 디아블로 야영지 같은 개념)
- 필드: 뼈대(입구·동굴 입구·이벤트 자리)는 고정, 지형·소품·몬스터는 들어갈 때마다 생성. 던전도 생성.
- 큰 마을 오른쪽 끝: 경비병 → 던전 가는 길. 왼쪽 끝: 경비병 → 필드(지역 선택. 미리 골라서 나감).
- 작은 마을용 경비병 2명(졸린 경비병·콧수염 배불뚝이): assets/npc_guard/guard_sleepy·guard_mustache — 케인: 나중에 작은 마을에 쓸 것
- 출구 경비병은 투구 쓴 평범한 경비병 그림(케인이 만들어 줌). 성문 경비병(라이너·에다)은 너무 잘생겼다는 평.

- 파밍 시스템 정리 문서(Claude Docs): https://claude.ai/code/artifact/7667c312-3148-40e3-b7f7-e2f191ec2915

## 확정 사항
- 아이템 이름은 옵션 이름이 앞 ("배짱의 구리 반지").
- 패드 테스트용 전체화면 버튼 필수.
- 능력치·스킬·숙련: docs/stats_skills.md, 무기 기준·숙련표: docs/weapons.md
- 경제·물가: docs/economy.md (물가 3규칙 확정, 돈 흐름 정리안은 확인 대기)
- NPC는 서 있거나 까딱이는 정도로 충분. 걷기 시트 캐릭터(검사·기사·용족 소녀)는 동료/빌런 후보.
- 가로 고정 2D 탑다운 액션 RPG. 마을 1개 + 던전 문(절차 생성). 월드맵은 보류.
- 시나리오는 비밀(src/story*). 케인에게 내용 공개 금지. 주는 던전 파밍.
- HUD: docs/hud_controls.md (우상단 미니맵, 무기1/무기2 교체, 스킬 최대 5 자유배치)
- 진행도·티어·길드: docs/progression.md, docs/guild_system.md
- 에셋 규칙: docs/asset_rules.md (문선팡 에셋, 임의로 자른 수풀·나무 금지. 정제된 시트만)
- 바닥은 이미 있음: assets/tiles(7테마), assets/edges, assets/dungeon/tiles·props
- 건물 16채(assets/buildings), 건물 부품 46(assets/building_parts), 실내 바닥·벽·가구(assets/interior), NPC 초상화 48(assets/npc)
- 시나리오 구성 완료(비밀): src/story.md(큰 줄기·건물 구입 순서), src/story/bible.md(NPC 48명 장부·건물별 역할), src/story/chains.md(연쇄 퀘스트 45개). 마을 배치 시 bible.md의 건물-역할 대응을 따른다.
- UI 키트: assets/ui/kit_c (인벤 01, 장비 02, 스탯창 02b)
## 마을 (game/town.html, 원본 src/town/)
- 정제된 바닥·건물 15채·소품 28종(assets/town_props), 그림자 굽기, 사람 14명(시나리오 장부 번호대로 문 옆), 대화창·상점창(무기·방어구점, 전당포)
- 비·꽃잎·구름·새 그림자·나무 흔들림, 뛰기(조이스틱 끝까지), 하루 8분 주기(아침·낮·오후·저녁·밤, 가로등 불빛) — 우상단 시간 글자를 누르면 시간대 넘김
- 행인 5명 걷기(assets/characters/villager_*), 낮에는 돌아다니고 밤에는 집으로
- 인터페이스: 큰 공격 버튼·무기 교체·가방, 장비·능력치·가방 창(src/town/ui.js)
- 무기 모션 확정(케인 확인): 걷기 땐 무기 숨김, 공격 시 무기는 몸 뒤, 아래 공격은 이펙트만, 검 좌우는 앞·아래쪽에서 휘두름
- NPC 초상화 2배 업스케일(assets/npc_hd, Real-ESRGAN 애니 모델, 원본 유지)
- 날아가는 새 그림은 없음(그림자만). 필요하면 다음 시트에 날갯짓 2~3컷 새 추가.
