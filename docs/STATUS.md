# 현재 상태 (대화가 끊겨도 여기부터 읽을 것)

**장르 한 줄: 돈 밝히는 엘프의 코믹 자본주의 파밍 액션 코믹 롤플레잉**
**주인공: 루크레아 (Lucrea)** — 이름은 lucre(돈·이익)의 어감 + 스크루지 연상.
**제목 후보(케인): 자본주의 엘프의 이세계 모험기** — "이세계"는 "이 세계(this world)" 말장난. 다른 세계에서 넘어온 설정 아님.
**제목 후보 2(케인): 골드 퀘스트 사가 (GQS)** — 제안: 큰 제목 GQS + 부제 "자본주의 엘프의 이세계 모험기"
## 가장 중요한 원칙 (디자인)
- **한 씬 한 컷을 만들더라도 최종 상태 수준으로 만든다.** 대충 만들고 나중에 고치자는 방식 금지(두 번 일하게 되고 결과가 망가진다). 예전 테스트판 위에 덧대어 키우는 관성도 금지.
- 디자인은 싹 리빌드. 옛 그림과 새 그림을 찢어붙인 화면은 절대 안 됨.
- 기준: ① 통일감 ② 모션의 일치.
- 케인이 에셋으로 시안을 만들어 주면 그걸 참조해서 만든다. 설명 듣기 전엔 임의로 그리지 않는다.
  (HUD 시안은 받음 → docs/hud_controls.md. 마을은 케인 지시로 "일단 만들어 보고, 안 되면 GPT에게 구역별 한 장 지도를 그리게 해서 이어 붙인다". 마을은 클 필요 없음.)

## 세계 구조 (케인 확정 2026-10-03)
- 큰 마을(지금 만든 마을, 시나리오 중심) + 지역마다 작은 마을(상점 1~2, 여관만 있는 고정 쉼터, 디아블로 야영지 같은 개념)
- 필드: 뼈대(입구·동굴 입구·이벤트 자리)는 고정, 지형·소품·몬스터는 들어갈 때마다 생성. 던전도 생성.
- 큰 마을 오른쪽 끝: 경비병 → 던전 가는 길. 왼쪽 끝: 경비병 → 필드(지역 선택. 미리 골라서 나감).
- 작은 마을용 경비병 2명(졸린 경비병·콧수염 배불뚝이): assets/npc_guard/guard_sleepy·guard_mustache — 케인: 나중에 작은 마을에 쓸 것
- 출구 경비병은 투구 쓴 평범한 경비병 그림(케인이 만들어 줌). 성문 경비병(라이너·에다)은 너무 잘생겼다는 평.

## 확정 사항
- **여관 1단계 구현(2026-10-04)**: 큰 마을 기존 여관(house_blue)에 실내 맵을 연결. 기존 interior 에셋으로 홀/카운터/테이블/책장/벽난로 구성, 토비에게 레벨×8골드(임시)를 내고 HP·MP 완전회복+상태이상 해제. 잡담/용병은 준비 중 잠금. 실내 저장 후 재접속은 단순 규칙으로 여관 문 앞에서 재개.
- **감정(미확인 장비) 미리 구현(2026-10-04)**: 옵션 3개 이상 장비는 새로 생성될 때 미확인. 기본 능력치는 보이지만 옵션은 `???`로 가리고 효과도 비활성. 여관 토비 감정사는 티어×50골드, 생활스킬 감정은 마법/희귀/전설에 각각 랭크1/2/3 필요. 감정 전 판매가는 정상가의 50%. 이전 저장의 `unid` 없는 장비는 감정 완료로 취급.
- **퀘스트 HUD 개선(2026-10-03)**: 초상화 아래 의뢰 추적은 배경 패널/테두리를 제거하고 글자 그림자 위주로 표시. HUD를 누르면 길드 의뢰창으로 바로 연결.
- **마지막 위치 재개(2026-10-03)**: 세이브에 현재 맵/좌표/방향/필드 테마/던전 층을 추가. 앱 재실행 시 마을로 강제 복귀하지 않고 마지막 위치에서 재개. 던전은 같은 층을 다시 생성한 뒤 저장 좌표를 nearestSafePosition으로 보정해 시작하므로 층 진행은 유지되지만 랜덤 던전 내부 배치/몹 상태는 새로 생성될 수 있음.
- **마을 간 이동(2026-10-05 보정)**: 목적지 티어=필드 N칸 연속 이동. 중간 칸은 전투·파밍 전용이며 작은 마을과 필드 동굴은 마지막 칸에만 배치. 각 칸은 실제 메인 길이 끝나는 오른쪽 위에서 다음 칸으로 이어지고, 마지막 칸 오른쪽 끝에서 목적지를 선택한다. 왼쪽은 이전 칸/성 밖 복귀.
- **소형 필드마을 1차 구현(2026-10-05)**: 각 지역 마지막 필드 우상단의 마을 입구로 들어가면 별도 소형마을 맵으로 이동. 봄 초원을 기준형으로 분수광장·노점형 잡화상·교역상·장식물·행인을 배치하고, 다른 지역은 같은 구조를 복제하여 이후 전용 에셋만 덮어씌우는 방식으로 확정.
- **교역 UI 개편(2026-10-05)**: 일반 상점처럼 시장 물품/내 화물을 좌우 두 칸으로 항상 표시하고 사기/팔기 탭 사용. 짧게 누르면 1개, 길게 누르면 수량 입력창이 열려 다량 거래. 기존 지역 시세·화물칸·수레·시세수첩은 유지.

## 연결형 월드 · 야외 던전형 필드 (케인 확정 2026-10-05)
- 월드는 완전 오픈월드가 아니라 **마을과 지역이 여러 필드 구간으로 이어지는 연결형 월드**로 간다. 타이탄 퀘스트/디아블로처럼 야외 이동 중 전투·파밍이 실제 여행의 일부가 되어야 한다.
- **중간 필드 = 랜덤 생성되는 큰 야외 던전**. 단순 가로 직선 달리기 맵을 쓰지 않고, 가로폭을 줄이고 세로 깊이를 늘린 구역에서 시작→출구 주경로가 크게 굽고 샛길·막다른 길·야영지/폐허·몬스터·파밍 지점이 생긴다. 너무 복잡한 미로는 금지하고 주경로는 읽기 쉽게 유지한다.
- **각 지역의 마지막 필드만 고정맵**으로 유지한다. 작은 마을·상점/교역·NPC·필드 동굴·퀘스트용 고정 위치·다음 지역 출구는 마지막 맵에만 둔다.
- 1차 구현: 중간 필드를 기존 60×40 가로형에서 48×48 야외 던전형으로 바꾸고, 매 진입마다 주경로와 샛길2개를 새로 생성. 마지막 고정맵은 60×40 기존 구조 유지.
- 필드 난도는 이동을 귀찮게 만드는 것이 아니라 **달리기만으로 통과하기 어렵고 이동 중 자연스럽게 전투가 붙는 정도**로 한다. 전체 난이도는 스트레스보다 편한 재미 우선.
- 후속 확정: 타운포탈은 **가장 최근에 실제 방문한 마을**을 귀환점으로 고정하여 편도 교역+포탈 귀환 꼼수를 막는다. 필드 효용성/이동 실제화가 길드 개편·주식 놀이보다 우선.


- **물약 3종×7티어 체계(2026-10-13)**: 빨강=HP, 파랑=MP, 보라=HP+MP. T1~T7 기준 레벨은 1~10 / 11~20 / ... / 61~70이며 각 티어 끝 레벨(10/20/.../70)의 균형 성장 최대 HP·MP 약 30%를 고정 회복량 기준으로 사용한다. 기본 가격은 T1 HP 100G / MP 150G / 복합 200G부터 시작해 T7 HP 1,100G / MP 1,650G / 복합 2,200G까지 완만하게 상승. 지역 작은 마을 잡화점은 해당 지역 티어 물약 3종을 판매하고 큰 마을은 T1 기준. 물약 쿨타임은 3종 공용. 기존 단일 HP/MP 물약 저장은 T1 물약으로 이관. 7열×3행 물약 시트 자동 분할 로더 추가.

## 아이템 합산 체감 설계안 — 케인 확인 대기(3단계, 아직 미구현)
**목표:** 좋은 옵션을 더 모으면 계속 강해지되, 공격%·숙련·스킬/속성%를 곱해서 생기는 폭증을 줄인다. 1·2단계 몬스터/지팡이 조정은 구현했고, 아래 체감곡선은 승인 전 코드에 넣지 않는다.

### 제안: 합성 증가율 +50%까지 그대로, 이후 완만하게
- 평타: 현재 `(1+공격%/100) × (1+숙련피해%/100)`를 먼저 곱한다. 마법 평타는 마법공격%를 사용한다.
- 스킬: 위 값에 `(1+스킬피해%/100)`와 해당 속성%를 곱한다. 지팡이/비지팡이70% 하한의 숙련은 중복 계산하지 않도록 **기본 마법값과 숙련 보너스를 분리**한 뒤 한 번만 포함한다.
- 이 전체 배율을 M, 총 증가율을 `x=100×(M−1)`로 놓는다. 0≤x≤50은 그대로, x>50은 `E(x)=50+100×(1−exp(−(x−50)/100))`. 최종 피해는 `기본 피해×(1+E(x)/100)`이다. 음수 효과는 원래 감소율을 유지한다.
- 기본 무기치·힘/지능·NUM=100·스킬 고유 계수/랭크·무기 전용/타무기 보정은 곡선 밖에 둔다. 착용/드랍/희귀도/이미지/아이템 ID도 바꾸지 않는다. 치명타는 이 피해에 기존 규칙대로 적용한다.

|현재 합성 증가율|제안 실효 증가율|현재→제안 피해 배율|
|---:|---:|---:|
|+0%|+0%|1.00→1.00|
|+50%|+50%|1.50→1.50|
|+100%|+89.35%|2.00→1.89|
|+200%|+127.69%|3.00→2.28|
|+400%|+146.98%|5.00→2.47|

- 실효 증가율은 +150%에 점점 가까워진다(피해 증폭 약2.5배). 초반 보너스 합성 +50% 이하는 기존과 같고, 이후에도 옵션을 더하면 항상 강해진다. 갑자기 옵션이 무효가 되는 단단한 상한은 쓰지 않는다.
- 예: 공격+100%·숙련+25%는 원래2.50배, 제안2.13배. 여기에 스킬피해+100%까지 있으면 원래5.00배, 제안2.47배. 서로 다른 공격 보너스를 모아도 모두 같은 곡선을 거치므로 다른 종류 옵션으로 상한을 우회하지 않는다.
- **단점:** 같은 옵션을 많이 모을수록 한 줄의 추가 효과가 줄며 후반 장비/숙련 수익이 내려간다. 공격속도·치명타·랭크·광역/상태이상 효과는 이번 공격% 곡선 밖이므로, 이 설계 하나로 모든 빌드의 총 초당 피해를2.5배에 묶는다는 뜻은 아니다.

### 실제 아이템이 쌓인 뒤의 구현/검증 단계(승인 후 별도 작업)
1. 공통 순수 함수로 곡선을 적용하고 표시창에 원래 옵션 합계와 실제 증가율을 함께 보인다. 저장된 원본 옵션 수치는 그대로 보관하며 공격%를 저장 데이터에 덮어쓰지 않는다.
2. T1/T3/T7·숙련0/25/50·일반/희귀/전설·0/50/100/200/400/1000% 조합을 실제 장비 슬롯 수/옵션 개수 규칙 안에서 측정한다. 평타와 대표 스킬의 지속 공격(마나 회복·쿨타임 포함), 광역/지속 피해도 함께 비교한다. 추가 옵션 때문에 약해지는 경우/숙련 중복/비지팡이70% 하한 손실이 없어야 한다.
3. 좋은 희귀 장비는 일반 장비보다 확실히 빠르고, 완성 장비도 같은 티어 일반몹을 계속 한 방에 지우는지 별도 확인한다. 공격속도·치명타까지 합친 결과가 과하면 **그때 별도 체감곡선/상한을 제안하고 케인 확인**을 받는다(이번에는 미정·미구현). 몬스터를 아이템 옵션에 실시간 비례시켜 파밍 효과를 지우는 방식은 쓰지 않는다.
4. 승인 이후 구현할 때 skills/combat/save/growth 및 전체 워크플로 검사와 전후 측정표를 다시 기록한다.
