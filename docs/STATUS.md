## 가장 중요한 원칙 (디자인)
- **한 씬 한 컷을 만들더라도 최종 상태 수준으로 만든다.** 대충 만들고 나중에 고치자는 방식 금지(두 번 일하게 되고 결과가 망가진다). 예전 테스트판 위에 덧대어 키우는 관성도 금지.
- 디자인은 싹 리빌드. 옛 그림과 새 그림을 찢어붙인 화면은 절대 안 됨.
- 기준: ① 통일감 ② 모션의 일치.
- 케인이 에셋으로 시안을 만들어 주면 그걸 참조해서 만든다. 설명 듣기 전엔 임의로 그리지 않는다.
  (HUD 시안은 받음 → docs/hud_controls.md. 마을은 케인 지시로 "일단 만들어 보고, 안 되면 GPT에게 구역별 한 장 지도를 그리게 해서 이어 붙인다". 마을은 클 필요 없음.)

## 세계 구조 (케인 확정 2026-10-03)

- 큰 마을 오른쪽 끝: 경비병 → 던전 가는 길. 왼쪽 끝: 경비병 → 필드(지역 선택. 미리 골라서 나감).
- 작은 마을용 경비병 2명(졸린 경비병·콧수염 배불뚝이): assets/npc_guard/guard_sleepy·guard_mustache — 케인: 나중에 작은 마을에 쓸 것

- **전투 체감 개편 1차 구현 완료 (2026-10-03)**: 필드·던전 몬스터가 같은 티어 안에서 플레이어 레벨(티어 내 1~10)을 따라 HP/공격력/속도가 완만하게 증가. T1 봄부터 늑대 돌진(pounce), 토끼 회피(dart), 고블린 돌 던지기, 슬라임 둔화 장판을 사용하고 기존 상위 특수기술도 유지.
- **플레이어 스킬 1차 강화 완료**: 화염구=큰 광역+화상, 얼음=광역+둔화/상위 랭크 빙결, 치유=큰 즉시회복, 강베기=강한 전방 타격+경직, 회전베기=넓은 전방위 타격+경직. 합성 효과음/햅틱과 코드 기반 타격·폭발·빙결 연출 강화.

## 무역·지역 작은 마을 (2026-10-03)
- 큰 마을 기존 도구점을 **교역소**로 전환. NPC 핀이 교역소 직원으로 거래를 연다.
- 7개 필드의 예약 구역에 **상인협회 + 여관** 작은 마을을 자동 배치. 몬스터는 이 예약 구역에 스폰하지 않음.
- 무역품 25종, 큰 마을+7지역 별도 시세. 대표 장거리 차익 예: 봄 곡물 → 화산 식량 수요.
- 화물 24칸, 품목당 최대 50개, 평균 매입가·현재 매각가·예상 손익 저장.
- 같은 지역에 같은 품목을 많이 팔면 5개마다 -1%, 하루 최대 -10%만 내려감.
- 무역 상태를 포함한 전체 성장 저장은 **arpg_save_v3**. v1/v2는 새 장기 성장판에서 완전 폐기.
- check_trade.py가 7지역 협회 생성, 실제 협회 상호작용, 봄→화산 차익, 저장/복원을 검사.
- 정확한 품목 기본가·지역 배율은 초기 테스트 값. 케인 실제 플레이로 조정.
- 케인이 18시대에 이전 `dungeon.js 수정 금지` 제한을 해제. 현재 던전도 7티어 성장 규칙에 통합.

## 장기 성장·전투·파밍 개편 (2026-10-03 18시대)
