# REBOOT V2 — IMPLEMENTATION HANDOFF (봉인본)

## 현재 상태
- 이 브랜치는 **시나리오 문서 전용**.
- main/game/src/town 코드는 수정하지 않는다.
- 케인이 다른 창에서 진행하는 전투·UI·밸런스 수정과 독립.
- 실제 구현은 케인이 “붙여라/빌드해라”라고 승인할 때만 시작.

## 구현 순서
1. 케인의 현재 게임판 수정이 끝난 뒤 최신 main을 기준으로 새 구현 브랜치를 만든다.
2. MAIN 001~010을 V2로 교체한다.
3. 케인이 초반 실제 플레이로 대사/동선 체감 확인.
4. 통과하면 MAIN 011~070을 데이터로 일괄 반영.
5. 서브퀘 45개는 메인과 별도 데이터로 순차 연결.
6. 전체 자동검사.
7. 마지막에 한 번만 game/town.html 빌드/게시.

## 구현 전 필수 기능 점검
V2는 아래 범위 안에서만 설계했다.
- talk
- visit
- kill
- collect (랜드마크/현장 근거 필수)
- deliver
- trade buy/sell
- shop buy
- dungeon floor visit
- boss clear
- 간단한 scene dialog

추가 구현이 있으면 좋은 기능:
- 특정 오브젝트 상호작용/레버
- 시간대(밤) 조건
- NPC/환경 대사 상태변화
- 퀘스트 후 지름길/가격/재고 변화
- 선택 동행 NPC

하지만 이 기능들이 없다고 전체 시나리오가 막히게 만들지 않는다.
없는 기능은 방문/대화/현장 수집으로 대체 가능하게 작성한다.

## 신규 이미지 에셋 정책
현재 V2 본편 Lv1~70은 **새 캐릭터 원화 없이도 구성 가능**.
사용 가능:
- 기존 큰 마을 48 NPC 초상
- 루크레아
- 카엘렌(기존 대검 검사 시트)
- 러스티(기존 중장갑 캐릭터 시트)
- 기존 지역/몬스터/던전 에셋

새 이미지가 필요할 가능성이 있는 것:
- ASSET_STORY_V2_001: 공백회 일반 인물/후드 실루엣 1종 (기존 후드 NPC 재사용 가능하면 생략)
- ASSET_STORY_V2_002: 최종부 전용 적 실루엣/보스 (기존 몬스터로 대체 가능하면 생략)
- ASSET_STORY_V2_003: 특허장/고대 계약문서 아이콘 (일반 문서 아이콘 재사용 가능하면 생략)

에셋 요청 시 케인에게는 사용 이유를 말하지 않는다.
예: “문서 아이콘 1장, 오래된 양피지+붉은 인장, 투명 PNG” 정도만 제공.

## 초반 재구현 때 폐기할 것
- 현재 MAIN 001~010의 기존 대사.
- spawnOffset만으로 목적물을 플레이어 발밑/근처에 생성하는 방식.
- 퀘스트마다 루크레아가 돈 관련 한 줄로 끝내는 패턴.
- 시작 NPC와 목적지가 같은 화면에서 즉시 끝나는 회수 퀘스트.

## 초반 재구현 때 유지할 것
- 메인/서브/길드 분리 UI.
- 퀘스트 저장 구조.
- 길드 5개 한도.
- 상점/길드/교역 이벤트 훅.
- 기존 필드/던전 이동 구조.
- 메인 별도 추적 표시.

## 구현 QA
각 메인퀘 자동검사 외에 사람이 보는 항목:
- 시작 NPC에서 목적물이 화면 안에 바로 보이지 않는가?
- 최소 한 번은 “장소를 찾아가는 이유”가 있는가?
- 수집물 위치가 설명과 일치하는가?
- NPC 말투가 다른가?
- 루크레아의 돈 관련 직접 언급이 한 퀘스트 내 0~2회 범위인가? (필요하면 0회)
- 완료 뒤 무언가 달라졌는가?
- 2~3개 메인 뒤 사냥/교역 자유시간이 있는가?
