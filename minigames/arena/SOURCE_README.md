# 자동 검투 경기 · 연출 테스트

`index.html` 또는 `arena-auto.html`을 브라우저로 열고 중앙 FIGHT를 누르면 됩니다. 전투는 자동이며 공격 버튼은 없습니다. 종료 연출 뒤 FIGHT를 누르면 다시 경기합니다.

이번 빌드는 자동 전투와 연출을 보는 테스트입니다. 캐릭터 선택·베팅·배당·현금 정산은 아직 연결하지 않았습니다. 기존 주점과 QTE 브랜치는 유지했습니다.

## 전투

두 캐릭터는 각자의 공격 선호도로 주먹·발·마법을 고릅니다. 상성으로 공격권을 정하고 2~4회의 연타 피해를 적용합니다. 선호 공격에는 작은 피해 보너스가 있으며 치명타가 발생할 수 있습니다. 공격과 피격으로 필살기 에너지가 차고, 100이 되면 소비하여 6연타 필살기를 씁니다. 체력 0 또는 75초 종료 시 실제 남은 체력으로 판정합니다. 승패를 미리 정하거나 체력을 임의로 맞추지 않습니다.

## 구현 연출

- 대기 호흡, 공격 포즈 전환, 돌진·반동·압축·회전·피격 포즈.
- 짧은 타격 정지, 배경 흔들림과 확대, 연타 표시, 섬광, 빛줄기, 충격파.
- 불꽃·파편·별 입자, 번개, 필살기 충전 링과 화면을 가로지르는 확대 컷인.
- 생성한 타격·폭발·충전·승리·커튼·만화적 반동 효과음.
- 승자 승리 포즈로 팔짝 동작, 패자 무릎 꿇기 → 홍조 포즈 → 커튼 닫힘·흔들림·하트·금화 → 커튼 열림.

실제 장면은 커튼 안에서 보여주지 않습니다. 커튼 안 효과는 만화식 충돌·반동음입니다. 결과 연출은 약 7초입니다.

왼쪽 아래에 효과음, 일시정지, 전체화면, 초기화가 있습니다. 스페이스로 시작·일시정지할 수 있습니다. 화면을 다른 앱으로 전환하면 자동으로 일시정지합니다.

## 파일과 검사

`arena-auto-engine.js`가 전투 판정을, `arena.js`가 입력·화면·사운드·효과를 담당합니다. `arena-engine.js`는 이전 QTE 판정 코드로 보존되어 있으며 현재 HTML에서는 불러오지 않습니다.

`python3 arena/scripts/bundle.py`로 에셋을 포함한 단일 HTML과 ZIP을 다시 만듭니다. 외부 에셋 다운로드 없이 실행됩니다.

`node arena/tests/auto.test.cjs`: 160회 재현 가능한 전투 검사, 양쪽 승리, 필살기·치명타, 체력·에너지 범위, 타격 시에만 피해 적용, 일시정지·초기화·결과 유지.

Playwright 브라우저 검사: 공격 버튼 없음, 자동 공방, 컷인, 실제 한 경기 종료, 승자·패자 포즈, 커튼 개폐, 재경기·초기화, 전체화면, 오프라인 단일 HTML, 960×540 배율, 에셋 누락·스크립트 오류 확인. 실제 Android 기기 성능과 사운드 평가는 아직 하지 않았습니다.

`media/auto-demo.mp4`는 실제 브라우저 실행을 녹화한 무음 영상입니다. 실행 파일에서는 효과음이 재생됩니다.
