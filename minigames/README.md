# 골든퀘스트 미니게임 통합

본편 설정 → **주점 · 버블팡 · 격투장**에서 선택합니다. 마을/여관/지역 마을에서 입장할 수 있습니다. 위쪽 **← 모험으로**를 누르면 같은 자리로 돌아옵니다. 입장 동안 본편 전투와 시간 흐름은 멈춥니다.

- **주점:** 본편 금화로 영업합니다. 재고 구입, 매출, 급여가 같은 잔액에 반영됩니다. 도중에 나가거나 재접속해도 영업 상태를 이어갑니다. 생활 메뉴와 SD 슬랩스틱은 숨긴 최종본이며 커튼 서비스는 유지합니다.
- **버블팡:** 최종본 규칙과 이미지를 유지했습니다. 획득 소품/조각은 본편 저장에 함께 보관합니다. 본편 장비/금화로 교환하는 기능은 아직 넣지 않았습니다.
- **격투장:** 실비아/니샤 중 선택하고 판돈을 입력합니다. FIGHT를 누를 때 판돈을 차감합니다. 실제 경기에서 승리하면 원금 포함 2배, 무승부면 원금을 받습니다. 패배하거나 경기 도중 나가면 판돈을 잃습니다. 완전 자동 경기이며 카드/4인 명단/필살기 수동 가위바위보/연승 회수는 후속 작업입니다.

PR #19로 현재 본편 main에 통합되었습니다. **건물 입장 연결·스토리 해금·주점 직원 영입·격투장 선수 영입은 후속 연결 작업**이며, 이번 병합에서는 임의로 열지 않았습니다.

## PC 실행

GitHub Actions의 **미니게임 통합 미리보기**가 성공하면 `Golden-Quest-minigames-preview` 실행 묶음을 다운로드하고 압축을 풉니다. Python 3이 설치된 PC에서 `실행하기.bat`를 누릅니다. 브라우저가 먼저 열려 연결 오류가 보이면 서버 창이 뜬 다음 새로고침합니다. 서버 창을 닫으면 실행도 끝납니다.

소스에서 직접 실행하려면 저장소 최상위에서:

```sh
python -m pip install pillow numpy scipy
python src/town/build.py
python -m http.server 8767 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8767/game/town.html`을 엽니다. 첫 빌드는 그림 압축으로 오래 걸릴 수 있습니다. `game/`은 빌드 결과이며 직접 커밋하지 않습니다. 통합본을 main에 반영하면 기존 서버 빌드가 본편을 갱신합니다.

## 검사

`src/town/check_minigames.cjs`는 임시 서버를 열어 실제 브라우저에서 입장/일시정지/복귀, 주점 한 판/급여/공유 금화/중간 복원, 소품 저장, 격투장 선차감/정산 중복 방지, 재접속과 이전 세이브를 확인합니다. Playwright가 필요합니다.

```sh
npm install --prefix /tmp/gqs-test playwright
node /tmp/gqs-test/node_modules/playwright/cli.js install chromium
NODE_PATH=/tmp/gqs-test/node_modules node src/town/check_minigames.cjs
node tools/check_save_sync.js
```

## 개발 인계

- 출처: Tavern-Game `codex/tavern-business-only`의 주점/arena, `762625e`의 Bubble Pang v0.2.5만 이식했습니다. 기존 개별 저장을 자동 수입하지 않습니다.
- 본편 `arpg_save_v3.minigames` 안에 진행을 함께 저장합니다. 저장 시각 경쟁이나 새 동기화 규칙을 만들지 않았습니다.
- `src/town/minigames.js`: 본편 입장·복귀와 금화/저장 연결.
- `minigames/bridge.js`: 본편에서 실행될 때만 활성화하는 연결. 각 게임의 독립 실행은 기존 저장을 사용합니다.
- 주점은 진행 중 모델을 그대로 보관하고 표시용 이벤트/창/드래그만 정리합니다. 본편 금화가 변경된 후 재입장할 때 현재 잔액을 사용합니다.
- 격투장 판돈은 경기 시작 즉시 저장되고 승패 정산은 한 번만 수행합니다. 앱을 종료한 미완료 경기는 판돈 소멸이며 재접속 보상을 생성하지 않습니다.
- 버블 소품은 기존 배열 형식 그대로 보존합니다. 드롭 카드/장비/교환 비율은 별도 합의 전까지 추가하지 않습니다.
- 주점 그림과 코드에서 원본 출처 문서/권리 표기를 확인할 때는 Tavern-Game의 기존 문서도 함께 보관/참조해야 합니다.
