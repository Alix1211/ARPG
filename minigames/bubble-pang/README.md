# 소품 버블팡 (Bubble Pang) v0.2.5 · 담당자 인수인계

> **기준 파일:** `minigames/bubble-pang/index.html` (현재 최종 테스트본, 단일 HTML)
>
> **상태:** 독립 미니게임 시제품. 주점 본편과 **아직 통합하지 않음**. 기존 본편 코드는 이 브랜치에서 건드리지 않았음.

## 1. 사용자 확정 방향
- 기존 HTML과 실제 제공 에셋을 우선 사용한다. **컨셉아트/새로운 시안 이미지부터 만들지 않는다.**
- 중앙 버블 게임판만 어두운 반투명 배경을 사용한다. 그 외에는 판때기/박스형 UI가 배경을 가리지 않게 한다.
- 특히 **실제 캔버스 바깥에 남는 큰 반투명 stageShell 배경을 다시 만들지 않는다.** v0.2.5에서 이를 투명하게 처리했다.
- 좌하단 캐릭터는 크게 등장하며, **사용자 선택/클릭 없이 자동 교체**한다. 전환은 좌우 이동이 아닌 **페이드인/페이드아웃만**.
- 상단의 커다란 게임 제목은 화면을 낭비하므로 제거하고 점수·하강 카운터·획득은 작은 HUD로 처리한다.
- 테스트 중 사용하기 위한 **전체화면 버튼 1개**를 유지한다.
- UI는 기존에 사용자가 좋다고 평가한 간결한 반투명 대화창을 참고한다.
- 시각적 수정은 **실행 가능한 HTML/CSS/JS**에 반영해서 확인할 것. 별도의 그림만 보여주고 완료로 보고하지 말 것.

## 2. 현재 게임 규칙 / 유지사항
- 같은 종류 버블 3개 이상 연결 시 제거, 연결이 끊긴 버블도 낙하/수집한다.
- **5발마다 한 줄이 내려옴**. 발사체가 붙은 뒤 하강한다. 실패선에 도달하면 게임오버.
- 소품 종류별로 10개 혹은 20개를 모아 완성 소품으로 환산하고, 조각/완성 수량은 localStorage에 저장한다.
- 중앙 버블 조준 점선 및 실패선은 **게임 규칙의 일부이므로 제거하지 않는다**. 사용자가 삭제하라고 한 것은 보드 바깥에 남는 불필요한 **큰 직사각형 배경/테두리**다.
- 캐릭터, 수집 보상, 저장 구조, 기존 실제 이미지 에셋을 보존한다. 새로운 성장/특수버블/경제 기능을 임의로 늘리지 않는다.

## 3. 실행 및 기술 메모
- `index.html`을 브라우저에서 열면 된다. 배경/버블/캐릭터 이미지가 data URL로 내장된 단일 파일이다.
- 주 대상 화면은 **16:9 가로 게임 화면**이다. 모바일 Android Chrome에서는 전체화면 버튼을 시험한다.
- 소스에는 버전별 CSS 오버라이드가 누적되어 있으므로 이후 정리 시 적용 우선순위와 반응형 레이아웃을 조심해야 한다.
- 코드 문법 검사는 이전 작업에서 통과했으나 **v0.2.5의 실제 Android 기기 렌더링/상호작용 검증은 완료했다고 주장하지 않는다**.
- 본편과 통합 시에는 독립 브랜치 코드를 별도 검토 후 필요한 부분만 병합하고, 본편의 직원/재화/보상 체계와 저장키 충돌을 확인한다.

## 4. 담당자에게
사용자는 불필요한 기획 확장·컨셉아트·임시 모형과, 배경을 가리는 의미 없는 거대 UI 박스에 강한 불만이 있다. **작게 요청받은 수정은 정확히 그 부분의 실제 코드만 고칠 것.** 버그가 생기면 이전 버전으로 무턱대고 되돌리지 말고 현재 파일과 차이를 확인한다. 수정 후 실행 화면으로 검증하여 보고한다.
