## 먼저 테스트할 흐름

1. 처음 열리는 **생활 페이지**에서 접객 직원 6명을 편성합니다. 기본 0~5번이 접객, 나머지 4명이 휴식입니다.
2. **교육**에서 비접객 직원을 고르고 교육 종류/초급·중급·상급을 선택해 배정합니다. 선택만으로 비용을 지불하지 않습니다.
3. **휴식**에서 교육 대신 쉬게 할 직원을 배정할 수 있습니다.
4. **오늘의 일정**에서 10명 전체의 접객·교육·휴식을 확인합니다. 교육 직원을 접객으로 교대하면 그 직원의 교육 예약은 취소되고, 교대한 직원은 휴식으로 바뀝니다.
5. **장보기**는 시장 장면에서 정상가로 물건을 구매합니다. **진료실**에서는 부족 체력 1당 1G를 지불해 즉시 회복합니다.
6. **이야기하기**에서 직원과 대화합니다. 하루 2명, 같은 직원은 하루 1회입니다. 선택에 따라 친밀도와 능력이 실제로 상승하며 침실·서재·역할 연습실로 장면이 바뀝니다.
7. **오늘 일정 진행**을 누르면 교육비를 한 번 지불하고 낮 12~18시 일정이 시작됩니다. 3교시가 각각 실제 5초로 진행됩니다. 상단 시각과 교육 진행 막대를 확인하세요.
8. 기존 SD와 배경 위에서 교육 동작을 표시하고, 교시마다 능력·체력이 변합니다. 종료 후 직원별 실제 상승치가 표시됩니다.
9. **주점 영업 시작**으로 밤 18~24시 영업을 합니다. 영업 6시간은 실제 3분으로 압축됩니다. 남은 실제 초도 상단에 표시됩니다.
10. 하단 대기 손님 초상화를 빈 테이블로 끌어놓고, 대기 직원 초상화를 해당 테이블로 끌어놓습니다. 드래그 중에는 시간이 멈추고 세 가지 궁합을 미리 보여줍니다. 기존 터치 선택 방식도 유지했습니다. 요청 아이콘을 누르고 작은 창에서 주문/서비스/연장/계산을 선택합니다. 대응창과 배치 선택 중에는 시간이 멈춥니다.
11. 마감 후 기존 손님까지 계산하면 장부 결산입니다. 교육비·치료비·재고 사용 원가·심부름값·급여가 반영됩니다. **다음 날 준비**로 생활 페이지에 돌아갑니다.

## 이번에 실제로 연결한 시스템

- 주점과 별도의 생활 페이지. 주점 배경을 흐리게 깐 생활 메뉴에서 교육/휴식/장보기/이야기/일정/진료실로 이동합니다.
- 이름·성격·접객 성향·외모·분위기를 가진 직원 10명. 시험 배분은 **S 4 / M 4 / 미발현 2**입니다.
- 성장 능력은 **화술 / 품격 / 서비스 / 체력** 4가지입니다. 기본 합계는 각각 190, 상한은 100입니다. 현재 피로(체력 잔량)는 별도입니다.
- 6명 접객 / 4명 교육·휴식. 동시에 이중 배정할 수 없으며 낮 일정 진행 후 편성 변경을 막습니다.
- 교육 6종: 접객 연습(품격), 청소 실습(서비스), 역할 연습(품격), 발성·표현(화술), 서재 공부(화술), 체력 단련(체력).
- 초급은 조건 없음, 중급은 해당 능력 45 이상, 상급은 65 이상. 단계에 따라 비용·상승치·피로가 증가합니다. 화면에서 결제 전에 모두 확인 가능합니다.
- 초급 일일 상승은 +4~5, 중급/상급은 각각 1.5배/2배 반올림입니다. 초급 수강료 45~80G. 돈과 체력이 부족하면 거절합니다.
- 휴식은 체력 잔량 +45, 슬라임은 +6 추가 회복입니다. 밤 영업이 끝난 뒤 하루 수면 회복 +30이 따로 적용됩니다.
- 접객은 교육보다 느리게 성장합니다. 메뉴 제공 시 서비스 +0.2, 일반 서비스 시 관련 능력 +0.4. 체력 잔량 25 미만에서 무리하면 품격 -0.1입니다.
- 교육 경험치 +30, 응대 경험치 +4. 100 경험치마다 레벨이 상승합니다. 레벨 자체가 모든 능력을 자동 상승시키지는 않습니다.
- 대화로 친밀도 +3~4, 관련 능력 +1. 로제/루루는 친밀도 12 이상이면 대화 화면에서 S/M 역할을 선택해 성향을 발현할 수 있습니다. 한 번 발현한 뒤에는 뒤집을 수 없습니다.
- 손님은 원하는 접객 성향/외모/분위기를 갖습니다. 직원 배치 미리보기에서 일치 개수(0~3)와 궁합을 확인합니다. 능력과 피로도 궁합에 반영됩니다.

이름과 성장·가격 수치는 시험안입니다. 데이터는 `js/data.js`에서 조정할 수 있습니다. 고유 특성 이름과 성격은 기록했지만, 슬라임 휴식 보너스 외의 종족별 패시브 효과는 아직 구현하지 않았습니다.

## 경제와 저장

시장 준비 구매는 정상가입니다. 밤 영업 중/마감 응대 중 긴급 발주는 **심부름값 포함 두 배**이며 판매가는 같습니다. 종료 후 발주는 막습니다. 재고 구매는 즉시 입고됩니다.

- 영업 이익 = 매출 − 사용 재고 원가 − 급여 − 선물 − 심부름값 − 치료비 − 교육비
- 마감 현금 = 시작 현금 + 매출 − 재고 매입액 − 심부름값 − 급여 − 선물 − 치료비 − 교육비
- 재고 가치 = 시작 재고 가치 + 재고 매입액 − 사용 재고 원가

심부름값을 재고 가치에 더하지 않습니다. 교육비는 일정 시작 때 한 번, 치료비는 치료 때 한 번 차감됩니다.

준비 중 구매·편성·일정 변경·대화·치료, 교육 시작/교시 종료/교육 종료, 영업 결산과 다음 날에 자동 저장합니다. 교육을 도중에 다시 열어도 마지막 교시 경계부터 이어지며 수강료를 중복 차감하지 않습니다. 교시 중간 최대 5초가 돌아갈 수 있습니다. 밤 영업 도중에는 저장하지 않습니다.

v0.4 저장 키는 `fantasy-tavern-v04`이며 v0.2/v0.3 저장을 읽어 가져올 수 있습니다. 이전 저장은 그대로 남겨둡니다. 브라우저나 실행 경로가 바뀌면 저장 위치가 달라질 수 있습니다.

## 에셋 및 구현 범위

새 이미지는 생성하지 않았습니다. 제공한 주점/장부/메뉴/초상화/큰 일러스트와 SD, 교육 6장·시장·진료실의 기존 배경을 사용했습니다. SD 동작은 이동·회전·확대·축소로 구현했습니다. 서재 공부에서는 기존 장부 이미지를 작은 책으로 사용합니다.

평상복 원본은 현재 받은 파일에서 확인하지 못해 대화에서는 기존 접객복 일러스트를 표시합니다. 평상복으로 가장하지 않았으며 원본 확인 후 의상 경로를 연결할 수 있습니다.

커튼 특별 서비스, 의상 교체, 신규 효과음, 장편 개인 스토리는 이번 빌드에 포함하지 않았습니다. 대화는 직원별 소개 대사와 선택 결과가 연결된 첫 단계입니다. 전원 성인 캐릭터입니다.

## 코드 구조

- `js/data.js`: 직원, 성장 능력, 교육 6종/단계, 대화 선택지, 시험 수치, 메뉴/접객 데이터
- `js/engine.js`: DOM과 분리한 영업·재고·회계의 기존 핵심
- `js/growth-engine.js`: 하루 일정, 교육·휴식·대화·성향 이벤트·성장·저장과 영업 연결
- `js/drag-input.js`: 마우스/터치/펜 공통 드래그, 좌표 축소, 미리보기, 확정·취소·입력 정리
- `js/life-view.js`: 독립 생활 페이지와 실제 SD 장면
- `js/render.js`: 주점 화면·장부·입력·전체화면 및 생활 페이지 연결
- `style.css`: 가로 화면 배치와 코드 애니메이션

## v0.5 조작과 화면 개선

- **손님 → 테이블:** 드래그해 놓으면 즉시 착석. 빈 테이블만 강조합니다.
- **대기 직원 → 손님 테이블:** 성향/외모/분위기 일치 여부와 예상 궁합을 옆 창으로 표시하고, 놓을 때 확정합니다.
- **직원 자동 교체:** 이미 직원이 있는 테이블에도 대기 직원을 놓을 수 있습니다. 기존 직원은 대기로 돌아오며 손님의 주문·주문 지연 시간·금액·이용 진행은 그대로 이어집니다. 교체 자체로 인사 비용이나 주문 금액을 다시 청구하지 않습니다.
- **담당 해제:** 테이블 직원 초상화 또는 담당 중인 하단 슬롯을 하단 직원 영역으로 끌어놓습니다. 새 직원을 배치할 때까지 요청을 보존합니다. 오래 방치하면 이용한 금액을 계산하고 퇴장합니다.
- 다른 손님을 맡고 있는 직원을 다른 테이블로 빼앗아 배치하지 않습니다. 먼저 담당을 해제한 뒤 배치할 수 있습니다.
- 테이블 밖에 놓기, Esc, 터치 취소, 화면 크기 변경 또는 다른 앱 전환은 드래그를 취소합니다. 수동 정지 상태는 드래그 후에도 유지됩니다.
- **교육 드래그:** 왼쪽 직원과 오른쪽 교육 아이콘을 중앙 장면에 놓습니다. 둘이 모이면 해당 직원의 교육 일정으로 확정합니다. 직원 먼저/교육 먼저 어느 순서든 가능합니다. 직원만 놓으면 선택 상태이며 비용은 아직 지불하지 않습니다. 배정된 조합의 교육 아이콘을 바꾸면 일정도 교체됩니다.
- 휴식 화면에서는 직원 초상화를 중앙에 놓으면 휴식으로 배정됩니다. 일정 진행 전까지 가능합니다.
- **교육 배경 오류 수정:** 직원을 선택하면 자신의 실제 일정·교육 단계로 표시합니다. 진행 중/종료 후에는 다른 수업의 미리보기로 실제 일정이 바뀌지 않습니다.
- SD는 수업에 따라 바삐 왕복 달리기, 좌우로 청소하기, 인사하기, 독서, 통통 뛰기, 달달 떨기, 수면 호흡과 Z 표시를 구분합니다.
- 보유 원본에서 자른 교육 아이콘·양피지 간판과 기존 초상화 프레임을 실제 적용했습니다. 기존 메뉴·책·하트 아이콘도 사용했습니다. 새 이미지는 생성하지 않았습니다.

v0.4 성장 저장 형식을 그대로 유지합니다. 이번 버전은 교육·접객 성장 수치를 바꾸지 않았습니다. 드래그는 Chromium 마우스/실제 터치 이벤트와 960×540 축소 화면에서 검사했으며 Android 실기기는 미검증입니다.

## v0.7 — 색상 복구, 특별 코스, 사운드

- v0.5의 CSS와 생활 배경 명암으로 복구했습니다. v0.6의 제공 소품/액자 배치는 `props.css`에서 유지합니다. 파스텔 CSS의 적용은 해제했고 이전 스타일 파일은 기록용으로만 남겼습니다.
- 사용자 제공 72개 코스를 직원 ID/성향/단계별로 등록했습니다. S 4명, M 4명, 미발현 2명입니다. 로제/루루는 친밀도 12 이상에서 이야기하기의 이벤트로 S/M을 선택하며 선택한 방향의 6개 코스만 표시합니다.
- **서비스 요청 → 특별 코스 추천하기**에서 조건과 선택지를 확인하세요. 일반 접객도 계속 선택할 수 있습니다. 미해금 코스에는 부족한 조건이 표시됩니다.
- 특별 코스는 **연장 1회 이후**, 또는 **지명 단골에게 메뉴 1회 제공 이후** 이용할 수 있습니다. 손님이 원하는 성향은 반드시 일치해야 합니다. 각 방문에서 1회만 가능합니다.
- 테스트용 수치: 1단계 Lv.1 / 원하는 능력 35 / 품격 25 / 궁합 1개 이상, 2단계 Lv.3 / 능력 55 / 품격 45 / 궁합 2개 이상, 3단계 Lv.6 / 능력 75 / 품격 65 / 궁합 3개 일치. 능력은 손님의 화술·품격·체력·서비스 요구에 대응합니다.
- A/B의 금액·피로: 1단계 160/180G와 14/16 체력, 2단계 300/320G와 22/24 체력, 3단계 520/540G와 32/34 체력. 능력 상승 +0.5/+1/+1.5, 친밀도 +1/+2/+3, 경험치 +6/+12/+18입니다.
- 선택 시 이용 금액만 더하고 **손님 계산 때 현금·매출에 한 번 반영**합니다. 코스 금액은 매출에 포함되며 장부에 별도 참고 금액으로 표시합니다.
- 3.6초 공통 커튼 닫힘→하트→금화→열림 연출 중 다른 손님의 시간과 입력을 잠급니다. 연출 안의 일시정지/계속 버튼과 다른 앱 전환 정지도 지원합니다. 커튼 안 장면은 그리지 않습니다.
- 주점 등급은 테스트용 누적 매출 기준: 동네 0G / 소문난 5,000G / 왕실 20,000G입니다. 해당 등급의 제공 커튼을 자동 적용합니다. 직원 코스 단계와 주점 등급은 별개입니다.
- 만족도 70 이상으로 계산한 손님은 담당 직원의 지명 단골로 기록합니다. 다음 날부터 대기열 일부에 재방문합니다. 단골 기록과 주점 누적 매출을 기존 v4 저장 형식의 추가 필드로 저장하며 이전 저장도 읽습니다.
