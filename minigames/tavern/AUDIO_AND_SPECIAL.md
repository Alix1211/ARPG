## BGM — 제공 sound.zip에서 매칭

## 효과음 — 모두 클릭 또는 드래그 확정으로 시작

| 행동 | 적용 |
|---|---|
| 대기 손님 클릭·입장 안내 | 제작한 문 삐걱/닫힘 + 작은 종 |
| 일반 테이블 클릭 | 제공 테이블 소음-웃음-남여 혼합.mp3의 2.7초 컷 |
| 요청이 있는 테이블 클릭 | 제작한 가벼운 알림 종. 자동 주문 등장에는 소리 없음 |
| 직원 선택·대화 | 제공 웃음 여 .wav의 짧은 컷, 역할 대화에는 여성 비명.ogg의 짧은 놀람 컷 |
| 만족한 접객·계산 | 제공 테이블 소음-웃음2.mp3의 웃음 컷 (군중 웃음으로 남성 독주 음성이라고 단정하지 않음) |
| 불만족 접객·계산 | 제작한 낮고 코믹한 투덜 톤. 실제 남성 배우의 화난 음성은 아님 |
| 음식/음료/맥주 제공 | 제작한 접시/유리잔/맥주잔 소리 |
| 구매·계산 | 제작한 동전 짤랑 |
| 교육 결과 확인 | 제작한 팡파르 + 제공 박수 함성.wav의 짧은 컷 |
| 레벨업·성향 발현 | 사용자 행동 중 발생하면 제작한 팡파르 |
| 교육 배정 불가 | 제작한 코믹 실수음. 확률적 교육 실패는 구현하지 않음 |
| 역할 연습 아이콘 선택·배정 | 제작한 휘익 + 만화적 충격음 |
| 특별 코스 선택 | 커튼 마찰음 |
| 커튼 클릭 | 만화 충격+남성 반응 / 휘익+여성 웃음 / 잔+동전 / 코믹 실수+하트의 4조합. 설명/대화창 없음. |
| 결산 후 다음 날 선택 | 제작한 짧은 종료음 |
| 진상 퇴치 | 타격/반응 파일은 준비. 미니게임 자체는 미구현 |

14개 원본 DSP 효과음은 `scripts/synthesize_sfx.py`로 재현할 수 있다. 사람 목소리를 새로 합성하지 않고 제공 녹음을 잘라 활용했다. 제공 여성 반응과 박수는 반복 자동 재생하지 않는다. 동시에 세 소리 이상 겹치면 가장 오래된 소리를 정지한다. BGM/효과음 토글과 음량은 별도 localStorage에 저장한다.

## 특별 코스 조건과 회계

- 사용자 제공 72개 코스·대사를 그대로 데이터화. 8명 48개 + 로제/루루 두 분기 24개.
- 성향 미발현자는 친밀도 12 이상, 이야기하기 이벤트로 한 방향을 발현. 양 방향을 동시에 표시하지 않는다.
- 서비스 요청에서 연장 또는 지명 단골의 메뉴 1회, 원하는 성향, 단계별 궁합/레벨/능력/체력 조건을 검사한다. 미해금 코스는 표시하지 않는다.
- 비용·성장·체력 수치는 README에 기록한 프로토타입 값. 특별 코스 선택 시 청구 금액만 증가하고 실제 현금/매출은 계산 시 수납한다. 코스 참고 금액을 매출에 또 더하지 않는다.
- 동일 방문 1회, 클릭 중복/과거 요청/다른 직원 코스/성향 불일치/체력 부족을 모두 거절한다.
- 해당 테이블만 32초간 커튼으로 가린다. 해당 직원의 이동/교체만 막고 다른 테이블은 계속 운영한다. 커튼 손님은 후속 요청을 만들지 않으며 열릴 때 원래 요청 순서로 이어진다. 전체 정지/대응창/장부가 열려 있으면 기존 규칙대로 커튼도 정지한다. 클릭은 소리/시각 연출만 반응하며 추가 청구가 없다. 남녀 모두 기존 홍조 이미지를 사용한다.
- 주점 등급은 누적 정산 매출 0/5,000/20,000G. 세 제공 커튼의 각 3×2 프레임을 6×1 시트로 재배열해 공통 연출에서 사용한다.
- 만족도 70 이상 계산 손님은 담당 직원 지명을 기록. 이후 영업일의 대기열에 일부 재방문. 실제 담당 직원이 지명 직원일 때만 메뉴 1회 조건으로 특별 코스 가능.
- 신규 저장 필드는 기존 v4 저장 형식의 `hospitality`; 이전 저장에서는 누적 매출과 단골 기록을 0/빈 목록으로 초기화한다.
